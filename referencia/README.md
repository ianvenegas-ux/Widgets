# Widget de referencia

Abrir [proyectos-movil-widget.html](./proyectos-movil-widget.html) para revisar el prototipo navegable que debe guiar la implementación real.

Debe conservar:

- lista móvil sin agrupación;
- logo Lilian Trade en la cabecera;
- navegación inferior con títulos grandes;
- panel deslizante;
- pestañas Proyecto / Chat;
- “Última actualización” debajo de “Seguimiento”.

El archivo usa datos de ejemplo y no contiene credenciales ni conexión a Supabase.
